⚙️ Functions and Pointers in C++
This folder contains code examples, practice solutions, and notes on functions, references, pointers, and memory management in C++.

📌 Key Concepts Included
🛠️ Functions: Function declaration, parameter passing (pass by value vs. pass by reference), default arguments, and function overloading.

🔄 Recursion: Call stack mechanics, base cases, and recursive problem solving.

📍 Pointers Basics: Memory addresses, address-of operator (&), dereference operator (*), and nullptr.

🎯 Advanced Pointers: Pointer arithmetic, constant pointers, and pointers to pointers (double pointers).

🧠 Dynamic Memory: Allocating memory on the heap using new and freeing it using delete to prevent memory leaks.

# 🗺️ C++ STL — Map Containers

Maps are STL containers used to store data in **key-value pairs**.

They are extremely useful in **DSA, competitive programming, and LeetCode** for:
- Frequency counting
- Fast searching
- Storing relationships between values
- Mapping one value to another

---

# 📌 Types of Map Containers

C++ mainly provides:

1. `map`
2. `unordered_map`
3. `multimap`
4. `unordered_multimap`

---

# 1️⃣ `map`

A `map` stores data in **key-value pairs**.

### Syntax

```cpp
map<key_type, value_type> name;
